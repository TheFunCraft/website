Requirements

● Minecraft 26.3
● Fabric Loader for 26.3
● Fabric API (the mod needs it)

Install

  1. Install Fabric
    Get the Fabric Loader for Minecraft 26.3 and create/select the Fabric profile. Add Fabric API to its mods folder.
  2. Add the jar
    Drop funclient-1.0.0.jar into .minecraft/mods (or your launcher profile's mods folder).
  3. Launch & open
    Start the Fabric profile and press Right Shift to open the ClickGUI.
  4. Get access
    First launch sends an access request. Run /funclient request in game if needed, then wait for an admin to approve you. Status re-checks every 30 seconds — no restart required.
